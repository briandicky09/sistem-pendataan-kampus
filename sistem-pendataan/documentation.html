1. Pendahuluan

Sistem Pendataan Kampus adalah aplikasi web untuk mengelola data mahasiswa, dosen, dan aktivitas akademik. Dibangun dengan HTML, Bootstrap 5, dan JavaScript murni — tanpa backend, sehingga mudah dijalankan langsung dari browser.

2. Memulai

Buka index.html di browser modern (Chrome, Edge, Firefox). Tidak perlu instalasi. Semua data demo disimpan di localStorage browser Anda.

sistem-pendataan/
├── index.html
├── input-mahasiswa.html
├── input-dosen.html
├── data-mahasiswa.html
├── data-dosen.html
├── live-preview.html
├── documentation.html
└── assets/
    ├── css/  (style.css, shell.css, topbar-extra.css)
    ├── js/   (script.js, shell.js, topbar.js, data-mahasiswa.js)
    └── img/  (profil.jpeg)

3. Modul Mahasiswa

3.1 Input Mahasiswa

Buka menu Form Input → Input Mahasiswa. Lengkapi NIM, nama, program studi, angkatan, dan kontak. Klik Simpan; data baru ditambahkan ke localStorage dengan progress 0% dan status aktif.

3.2 Data Mahasiswa

Tabel mahasiswa mendukung pencarian (nama/NIM), paginasi, indikator progress studi, serta aksi edit dan hapus.

4. Modul Dosen

4.1 Input Dosen

Lengkapi nama, username, kota, provinsi, dan kode pos. Centang persetujuan lalu klik Submit form.

4.2 Data Dosen

Daftar dosen lengkap dengan NIDN, prodi, jabatan akademik, dan status. Tersedia pencarian dan tombol Export CSV.

5. Pencarian, Komentar, Notifikasi

5.1 Pencarian global

Klik ikon di topbar (atau tekan /). Ketik untuk mencari halaman, mahasiswa, atau dosen dari satu titik.

5.2 Komentar

Klik ikon . Komentar tersimpan di localStorage dan dapat dibalas dari mana saja di sistem.

5.3 Notifikasi

Klik ikon . Setiap item dapat ditandai sudah dibaca, atau gunakan tombol Tandai semua dibaca.

6. Live Preview

Halaman Live Preview menampilkan modul lain di dalam iframe. Pilih halaman dari dropdown dan ubah ukuran (Desktop / Tablet / Mobile) untuk uji responsif tanpa berpindah halaman.

7. Shortcut Keyboard

  • / — fokus pencarian global
  • Esc — tutup panel aktif

8. FAQ

Apakah data tersimpan permanen?

Data demo tersimpan di localStorage browser. Untuk persistensi penuh, hubungkan ke backend (mis. Supabase) — sistem ini siap diintegrasikan.

Bagaimana mengganti foto profil?

Ganti file assets/img/profil.jpeg dengan foto baru (ukuran kotak direkomendasikan).
